# Ветки: эксперимент без страха

**Урок 3.3 · Модуль 3. Система контроля версий (Git)**

15 минут

---

## Метафора: параллельная вселенная

Представьте дерево.

- **Ствол** — основная линия истории (ветка `main/master`)
- **Ветка** — ответвление со своей историей коммитов
- В конце ветка либо **прирастает обратно** (merge), либо **отваливается** (удаление)

---

## На языке учёного

- `main` — то, что уже работает и опубликовано
- боковая ветка — «а давай попробую другой статистический тест»,
  «а что если violin-plot вместо box-plot»

Правило:

> Всё, в чём не уверены, что получится — делаем в отдельной ветке.
> Получилось — вливаем. Не получилось — выбрасываем, main не тронут.

---

## Когда создавать ветку

**Да:**
- пробуете новый статистический метод
- меняете формат графика под журнал
- применяете алгоритм из свежей статьи

**Нет:**
- исправили опечатку в README
- добавили одну статистику в готовый скрипт
- переименовали файл

Косметическое и точно безопасное → в main. Экспериментальное → ветка.

---

## Создать ветку в Gitnuro

**Branch → New Branch** → имя `experiment/mw-vs-ttest` → Create Branch

Имя — латиницей, со слэшем для группировки:
префикс `experiment/` помогает при навигации.

---

## Пробуем в ветке

```
В scripts/02_plot.py замени попарные t-тесты между группами
на попарные тесты Манна-Уитни. Сохрани p-значения,
перегенерируй figures/boxplot_rt.png. Не меняй ничего
вне scripts/02_plot.py и figures/.
```

Важно: «не меняй ничего вне…» — чем точнее границы, тем меньше сюрпризов.

---

## Решаем: влить или выбросить

**Влить (merge):**
1. Branch → Checkout → main (переключиться на main)
2. Branch → Merge into current branch → выбрать ветку
3. «Merge successful»

**Выбросить (не понравилось):**
1. Переключиться на main
2. Branch → Delete branch → подтвердить

В обоих случаях main остаётся целым.

---

## Про конфликты — вкратце

Иногда одна строка изменена в обеих ветках — при merge возникает **конфликт**.

Решение простое: попросить OpenCode разрешить:

> «В файле scripts/02_plot.py конфликт merge: посмотри две версии,
> оставь ту, что из ветки experiment, и удали маркеры конфликта».

---

## Итог урока

Ветка — это страховка.

> main не трогается ни при каких обстоятельствах,
> пока вы сами не нажмёте Merge.

Это и есть «эксперимент без страха».
