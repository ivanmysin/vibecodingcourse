# Инструменты: локальные скрипты и MCP-серверы

**Урок 4.4 · Модуль 4. Компоненты ИИ агента и их настройка**

15 минут

---

## «Руки» агента

OpenCode 2 — это не только «текст в чате». У него есть **инструменты** —
операции, которые он выполняет от вашего имени:

- читать файлы
- искать
- править
- запускать команды
- вызывать субагентов
- ходить во внешние сервисы

---

## Два типа инструментов

| Локальные (встроены в OpenCode 2) | MCP-серверы (внешние) |
|-----------------------------------|------------------------|
| `read` — прочитать файл | Context7 — актуальная документация |
| `edit` — отредактировать | Zotero — ваша библиотека |
| `shell` — выполнить команду | GitHub, PubMed, Notion, Slack |
| `glob`, `grep` — найти файл/текст | |
| `subagent` — вызвать субагента | |

**MCP** (Model Context Protocol) — стандартный протокол,
по которому OpenCode общается с внешними сервисами.

---

## Безопасность: read-only vs мутирующие

**Read-only** — только смотрят: `read`, `glob`, `grep` — безопасно.

**Мутирующие** — что-то меняют: `edit`, `shell`, запись файлов.
OpenCode согласует их через диалог подтверждения в Web-интерфейсе.

В OpenCode 2 права задаются в `permission`, а не в тексте промпта:

- `edit` — запись, изменение, patch
- `shell` — команды в оболочке
- `subagent` — запуск субагентов

## Зачем Context7

Context7 — MCP-сервер с актуальной документацией
pandas, scikit-learn, mne, seaborn и сотен других библиотек.

Без него модель опирается на свою память и может описывать
API, которого уже нет («галлюцинации про старые версии»).

## Локальные инструменты в работе

```
Найди все CSV-файлы в data/ этого проекта. Для каждого
посчитай число строк и число колонок. Сохрани сводку
в reports/csv_summary.csv. После — отчитайся в чате,
какие инструменты (read, glob, grep, shell, edit)
ты использовал на каждом шаге.
```

Один запрос — несколько инструментов: `glob` нашёл файлы, `shell` посчитал строки,
`read` прочитал заголовки, `edit` записал отчёт.

## Подключаем Context7 в OpenCode 2

В OpenCode 2 у Context7 есть **remote** MCP-сервер, поэтому npx не обязателен:

```
opencode mcp add context7 --url https://mcp.context7.com/mcp
```

Или попросите агента:

```
Подключи MCP-сервер Context7 к проекту.
Используй remote-сервер https://mcp.context7.com/mcp.
Проверь подключение через `opencode mcp list` и покажи
итоговый фрагмент `mcp.servers` из `opencode.jsonc`.
```

---

## Где это лежит в конфиге

В OpenCode 2 MCP-серверы живут под `mcp.servers`:

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "servers": {
      "context7": {
        "type": "remote",
        "url": "https://mcp.context7.com/mcp"
      }
    }
  }
}
```

Старая запись `mcp: { "context7": { ... } }` из V1 не используется.

---

## Самовалидация: агент проверяет себя

После подключения — самое важное. Просим агента проверить свой же результат:

```
Проверь себя: прочитай `opencode.jsonc` и `opencode mcp list`.
Подтверди, что:
1) MCP-сервер Context7 подключён и активен;
2) какой URL используется для запуска;
3) какой тип сервера (local или remote).

Если что-то не подключено — скажи, что исправить.
Не додумывай, читай конфиг и вывод команды.
```

Верим не «на слово», а конфигу и выводу `opencode mcp list`.

---

## Безопасность MCP

MCP-сервер = внешний сервис или локальная программа, которой уходят ваши запросы.

- Подключайте только доверенные серверы (открытый код, известные разработчики)
- Remote-серверы проходят OAuth или требуют ключ
- `permission` в `opencode.jsonc` ограничивает, какие MCP-инструменты разрешены
- Для локального сервера команда запуска — это тоже код: проверяйте, что запускаете

---

## Полезные команды V2

```
opencode mcp add <name> --url <url>     # remote
opencode mcp add <name> -- <command>    # local
opencode mcp list                       # список и статус
```

В чате: `/mcps` — посмотреть, подключить, отключить или авторизовать сервер.

## Итог урока

- Инструменты бывают двух типов: локальные и MCP-серверы
- Read-only безопасны, мутирующие — согласуются с вами
- В OpenCode 2 MCP настраивается через `opencode mcp add` и `mcp.servers`
- Context7 лучше подключать как remote-сервер
- Настройка — через OpenCode, проверка — через конфиг и `opencode mcp list`
