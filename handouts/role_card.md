# Карточка роли субагента

> Раздатка к урокам 4.3 и 4.7. Заполняется до создания агента.
> Роль — это не «персона», а результат, права и критерий готовности.

---

## Шаблон

```
Роль: <короткое имя>
Результат: <что агент возвращает — файл, таблица, PASS/FAIL>
Вход: <какие файлы и данные он получает>
Права: <что можно читать, что можно менять, что запрещено>
Критерий готовности: <проверяемое утверждение>
Остановка: <когда прекратить и вернуть управление>
Эскалация: <кому и когда>
```

---

## Пример 1. Reviewer (проверяющий)

```
Роль: reviewer
Результат: PASS/FAIL + замечания с файлом:строкой или DOI
Вход: SPEC.md, отчёт, артефакты (results/, figures/)
Права: только чтение; edit: deny, shell: deny, subagent: deny
Критерий готовности: каждое замечание подкреплено источником;
                     нет слов «кажется» и «вероятно»
Остановка: 3 однотипные ошибки → эскалация человеку
Эскалация: координатору/человеку
```

Для ревью кода можно разрешить `shell: ask` с allowlist на `git diff`, `git log`, `pytest`.

---

## Пример 2. Researcher (исследователь)

```
Роль: researcher
Результат: список источников + таблица «тезис → источник → статус»
Вход: вопрос, список баз (Zotero / PubMed / arXiv), ограничения по годам
Права: только чтение; edit: deny, shell: deny
Критерий готовности: у каждого тезиса есть проверяемая ссылка/DOI
Остановка: 3 источника не находятся → вернуть «не найдено»
Эскалация: координатору
```

---

## Пример 3. Executor (исполнитель)

```
Роль: executor
Результат: изменённые файлы в разрешённой области + отчёт
Вход: SPEC.md, список файлов, критерии приёмки
Права: edit только scripts/**, figures/**, reports/**;
       shell: ask с allowlist; subagent: deny
Критерий готовности: скрипт запускается, артефакты на месте
Остановка: 3 одинаковые ошибки → стоп
Эскалация: координатору
```

---

## Проверка перед созданием

- [ ] Роль возвращает **артефакт**, а не «мнение».
- [ ] У роли есть **права**, а не только текст в инструкции.
- [ ] Есть **критерий готовности**, который можно проверить.
- [ ] Есть **условие остановки**.
- [ ] Понятно, чем роль отличается от `@explore`/`@general`.
- [ ] Понятно, кто проверяет результат роли.
