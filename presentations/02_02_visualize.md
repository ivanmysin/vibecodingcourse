## Что такое тета-гамма сопряжение

В мозге есть ритмы разных частот:

- **тета** — медленный (5–10 Гц)
- **гамма** — быстрый (30–59 Гц)

**Phase-amplitude coupling (PAC)** — явление, когда фаза медленного ритма
модулирует амплитуду быстрого:

> Амплитуда gamma-колебаний выше на определённой фазе theta.

При ЧМТ эта связь ослабляется — это ключевое открытие статьи.

## Что считает modulation index

Идея простая:

1. Берём **фазу** тета и **амплитуду** гамма
2. Делим фазы на бины, в каждом считаем среднюю амплитуду gamma
3. Если амплитуда распределена равномерно → связи нет (MI ≈ 0)
4. Если амплитуда сконцентрирована в одной фазе → связь сильная (MI → 1)

MI = насколько «неравномерно» распределена амплитуда по фазам.

## Синтетические данные

Генерируем сигнал с известным свойством:

- низкая частота **5 Гц** модулирует высокую **32 Гц**
- **вариант 1**: сильная модуляция (амплитуда gamma сильно меняется по фазе theta)
- **вариант 2**: слабая модуляция
- к обоим добавлен шум

Теперь у нас есть «эталон»: сильная модуляция → MI высокий,
слабая → MI низкий.
