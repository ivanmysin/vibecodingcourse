# Поиск литературы через PubMed

**Урок 6.3 · Модуль 6. Продвинутые приёмы работы с ИИ агентом**

15 минут

---

## Что можно с помощью доступа к PubMed

- поиск генов и последовательностей ДНК
- структуры белков
- статьи по биомедицинской тематике, включая обзоры, клинические испытания, мета-анализы и т.д.

**ВАЖНО:** PubMed не даёт полных текстов статей, даже если статья в открытом доступе.

---

## MCP для биоинформатики

У PubMed есть официальный API. Существует множество обёрток над ним в виде MCP-серверов. Один из самых функциональных [`bioinformatics-mcp-server`](https://mcpservers.org/ru/servers/aiagentkarl/bioinformatics-mcp-server).

- ставится одной командой
- **API-ключ не нужен** — регистрироваться не надо
- внутри — 10 инструментов: гены, белки, последовательности, PubMed
- в OpenCode 2 добавляется через `opencode mcp add` и попадает в `mcp.servers`

---

## Три инструмента для работы со статьями в PubMed

- `search_pubmed` — найти статьи
- `get_pubmed_abstract` — полный абстракт
- `get_pubmed_citations` — кто кого цитирует

Вы описываете задачу по-русски — агент сам выбирает инструмент.

---

## Кейс: ищем литературу к нашему результату

Результат из 6.1: action recognition, accuracy = 0.82.

```
Найди в PubMed статьи про action recognition по pose keypoints
за последние 5 лет. Через MCP (search_pubmed).
Выведи таблицей: title, год, DOI, PMID.
Сохрани в reports/pubmed_search.md.
```

Агент сам вызывает инструмент поиска — без подсказки названия.

---

## Читаем абстракт

```
Возьми первую статью из списка. Покажи её полный абстракт
(через get_pubmed_abstract). Перескажи на русском в 3-4
предложениях: что они делали, какие данные, какой результат.
```

Не открываем статью вручную и не переводим с английского — агент.

---

## Смотрим цитирования

```
Посмотри, какие статьи цитируют первую (через get_pubmed_citations).
Выведи 3-5 самых свежих цитирующих статей: title, год.
```

Цитирования — это «кто продолжил эту работу»: готовый список
свежих статей для чтения.

---

## Проверка результата

Как всегда — не верим на слово:

> «Открой reports/pubmed_search.md. Проверь: каждый DOI/PMID
> реально существует? Статьи по теме, а не про другое?»

Агент может ошибиться в DOI или подсунуть нерелевантную статью.

## Итог урока

- PubMed — весь мир, Zotero — своя база
- MCP `bioinformatics-mcp-server`, без ключа
- В OpenCode 2 — через `opencode mcp add` и `mcp.servers`
- Три инструмента: поиск, абстракт, цитирования
- Fallback: `webfetch` к PubMed
