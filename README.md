# Вайбкодинг для наук о жизни — материалы курса

Здесь лежит то, что нужно во время просмотра уроков: презентации,
тексты запросов, небольшие датасеты и примеры конфигураций.

> **Чего здесь нет и почему.** Видео, графики и результаты работы кода
> в репозиторий не кладём — они либо тяжёлые, либо их проще получить
> самому, выполнив запрос из урока. Презентации лежат в Markdown,
> чтобы читаться прямо на GitHub, без скачивания.

---

## Что где

| Папка | Что внутри |
|---|---|
| `presentations/` | слайды 30 уроков в Markdown — смотреть прямо на GitHub |
| `prompts/` | тексты запросов к агенту, чтобы копировать без опечаток |
| `datasets/raw/` | небольшие датасеты, готовые к работе |
| `datasets/links/` | карточки тяжёлых датасетов: первоисточник, структура, лицензия |
| `handouts/` | раздатки: шпаргалки, чек-листы, памятки |
| `handouts/opencode.jsonc` | пример конфигурации прав OpenCode |

## Датасеты

### `datasets/raw/iris.csv`

Ирисы Фишера: 150 строк × 5 колонок.

```
sepal_length,sepal_width,petal_length,petal_width,species
5.1,3.5,1.4,0.2,setosa
```

Три вида по 50 цветков: `setosa`, `versicolor`, `virginica`.
Первоисточник — [UCI ML Repository, Iris](https://archive.ics.uci.edu/dataset/53/iris).
Положить в свою рабочую папку как `data/iris.csv`.

### ЭЭГ (урок 1.2)

Скачивать и готовить данные не нужно: записи лежат в папке `data/`
рабочего проекта вместе с описанием датасета — `data/Description.md`.
Именно этот файл открывает агент по промпту из урока.

В git записи не попадают — они тяжёлые (единицы гигабайт). Для чтения
на GitHub есть карточка `datasets/links/eegmmidb.md`: структура
датасета, условия записи, лицензия и цитирование.

Первоисточник — [PhysioNet, EEG Motor Movement/Imagery
Dataset](https://physionet.org/content/eegmmidb/1.0.0/), лицензия
ODC-By 1.0.

## Конфигурация OpenCode

`handouts/opencode.jsonc` — пример прав: запись в сырые данные запрещена,
удаление и перемещение файлов требуют подтверждения.

Важно: правило по образцу защищает от **случайного** удаления.
Против намеренного обхода (`find -delete`, `python -c "os.remove(...)"`)
нужен Docker или отдельный пользователь.
