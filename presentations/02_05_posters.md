15 минут

## Результаты готовы — теперь нужно показать их коллегам

Предполагается, что у нас уже есть статья с описаниями результатов и графики.

Мы хотим сделать:

- **постер** — на конференцию
- **слайды** — на доклад

Задача сводится к тому, чтобы красиво подать материал.

---

## Какие есть возможности по вёрстке

Агент лучше всего работает с обычными текстовыми файлами.

- LaTeX
- HTML
- Markdown/Marp
- pptx

Главное — указать агенту, **откуда брать** контент.

## Запрос к агенту: постер

```
Сделай постер для конференции на основе reports/run.md
и figures/. Сохрани как poster/poster.pdf.

Структура: заголовок, цель, методы, результаты (главный
график + таблица), вывод.

Числа бери из reports/run.md, не придумывай.
Сверстай через HTML и сгенерируй PDF сам.
```

---

## Запрос к агенту: слайды

```
Сделай слайды для доклада (5 слайдов) из того же материала.
Сохрани как slides/talk.pdf.

Слайды: титул, цель, данные и методы, результаты, выводы.
Сверстай через Marp и собери PDF сам.
```

---

## Проверка

> «Сверь числа на постере и в слайдах с `reports/run.md`.
> Графики на месте? Подписи на русском?»

Вёрстка может «съесть» подпись или перепутать график — проверяем.

---

## Итог урока

- Вёрстка — простой элемент: агент раскладывает готовый контент
- Постер и слайды — из одного материала
- Правило: мало текста, один главный график
