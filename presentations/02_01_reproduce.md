## Что такое клетка места (place cell)

**Клетка места** — нейрон гиппокампа, который разряжается,
когда животное находится в определённом месте арены.

Это место называют **полем клетки** (place field).

- Открыты в 1970-х (О'Киф), Нобелевская премия 2014 года
- Карта таких клеток — «внутренний GPS» мозга

Статья 1993 года предложила количественный метод —
**карту активации** и меру **пространственной информации**.

---

## Метод из статьи: карта активации

Чтобы построить карту активации клетки места:

1. Разбиваем арену на квадратные бины (ячейки)
2. Для каждого бина считаем:
   - **occupancy** — сколько времени животное провело в бине
   - число спайков, случившихся в бине
3. Скорость разряда в бине = спайки ÷ occupancy
4. Сглаживаем карту гауссовым ядром

Результат — тепловая карта: где клетка «стреляет» чаще всего.

---

## Метод из статьи: пространственная информация

**Spatial information (bits/spike)** — мера того, насколько разряды клетки
несут информацию о положении животного.

- Если клетка «стреляет» везде одинаково → информация ≈ 0
- Если строго в одном месте → информация велика

Типичное значение для клеток места CA1 —
**порядка 1 бит/спайк (диапазон ~0.5–2)**.

Это наша **опубликованная норма** для сверки.

## Откуда данные: ratinabox

`ratinabox` — Python-библиотека для симуляции:
животное движется по арене, а нейроны «разряжаются» согласно заданным полям.

Главное преимущество: **мы знаем истину**.

Поле клетки задано в симуляции — значит, мы можем проверить,
что наш метод его правильно восстанавливает.

## Шаг 3 подробнее: проверка на синтетике

Синтетика — это данные с известным правильным ответом.

1. Просим агента смоделировать сессию (ratinabox)
   с полем клетки в **известной точке** арены
2. Применяем метод
3. Смотрим, совпало ли восстановленное поле с заданным

Не совпало → метод реализован с ошибкой.

## Запрос к агенту

```
Смоделируй с помощью библиотеки ratinabox одну «сессию»:
животное движется по квадратной арене 1×1 м 10 минут,
одна клетка места с полем в известной точке.

Реализуй метод построения карты активации по статье
Skaggs, McNaughton, Gothard, Markus (1993):

1. Разбей арену на бины 30×30.
2. Для каждого бина посчитай время пребывания (occupancy)
   и число спайков.
3. Скорость разряда = спайки / occupancy.
4. Сгладь карту гауссовым ядром.

Построй heatmap карты активации и рассчитай пространственную
информацию (bits/spike) по формуле из статьи.

Проверь: восстановленное положение поля должно совпасть
с истинным из симуляции.

Все подписи на русском. Используй Python (ratinabox, numpy,
scipy, matplotlib).
```

## Сверка с нормой

После того как метод отработал на синтетике:

- пространственная информация должна быть порядка **1 бит/спайк**
- если получилось 0.01 или 100 — где-то ошибка

Плюс записываем в `analysis_log.md`:
какая статья, какой метод, какие параметры, какие результаты.
