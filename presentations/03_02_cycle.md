## Когда нажимать Commit

Два подхода:

- **«Гигантский коммит»** — работаем весь день, вечером коммитим всё пачкой.
  Минус: если завтра сломается — непонятно, какое из 20 изменений виновато.
- **Атомарный коммит** — после каждой осмысленной порции работы.

Добавили статистику — коммит. Построили график — коммит. Поправили подпись — коммит.

---

## Какие сообщения хорошие

- «добавлен box-plot по группам»
- «README дополнен разделом Методы»
- «скрипт: исправлена подпись оси Y»

Какие плохие:

- «fix», «update», «wip»
- «финальный финальный 2»
- «asdfg»

---

## Анти-паттерн

Файл `финальный_финальный_2` появляется, когда человек:

- не коммитил регулярно
- боялся сломать
- копил изменения
- а потом свалил всё в одну кучу с невнятным именем

Лечится привычкой атомарных коммитов.

## Цикл «правка → коммит»

1. Правка через OpenCode (обычным текстом)
2. Gitnuro → Local Changes → проверить файлы
3. Осмысленное сообщение
4. Commit

```
В scripts/02_plot.py увеличь шрифт подписей осей с 10 до 12
и добавь сетку. Запусти скрипт, сохрани новый PNG в figures/.
```

## Страховка 1: команда /undo

В OpenCode 2 `/undo` — это откат через snapshots:

- отменяет последний запрос и работу агента после него
- возвращает файлы к состоянию до шага — но только внутри Git-репозитория
- возвращает удалённый запрос в поле ввода, чтобы его можно было исправить
- можно применять несколько раз

```
/undo
```

- Вне Git `/undo` откатывает только разговор, но не файлы.
- Есть парная команда `/redo` — она отменяет подготовленный откат.
- Это «страховка до закрытия чата»; для важных изменений всё равно нужен Git.

---

## Страховка 2: revert в Gitnuro

Откат через Git — для случаев, когда ошибка нашлась **позже**:

- Открыть History
- Правый клик по коммиту → **Revert this commit**

Создаст новый коммит, отменяющий выбранный.
История не переписывается, цепочка сохраняется.

---

## /undo и revert — разные инструменты

| | `/undo` | revert |
|--|---------|--------|
| Где | OpenCode | Gitnuro |
| Что отменяет | последний запрос и работу агента; файлы — в Git-репозитории | любой коммит в прошлом |
| Когда | только что накосячили | ошибка обнаружилась позже |

---

## Три вопроса перед коммитом

1. Закончен ли смысловой кусок?
2. Пойму ли я сообщение через месяц?
3. Если это откатить — проект не сломается?

Если на все три — «да», коммитим смело.
