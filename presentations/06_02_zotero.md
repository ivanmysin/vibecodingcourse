## Своя база vs внешний поиск

Два способа найти научную литературу:

| Своя база (Zotero) | Внешний поиск (PubMed) |
|--------------------|------------------------|
| что вы **уже собрали** | что вы **ещё не нашли** |
| локальная библиотека | база публикаций всего мира |

Сегодня — про свою базу. Это первый кирпичик deep-search (урок 6.4).

## Zotero через MCP

Zotero — программа для хранения статей. Агент может получить к ней доступ через локальный
MCP-сервер. Существующие решения:

- [Zotero MCP](https://github.com/cookjohn/zotero-mcp)
- [Zotero MCP](https://github.com/54yyyu/zotero-mcp)
- [ZotPilot](https://github.com/xunhe730/ZotPilot)

В OpenCode 2 сервер добавляется командой `opencode mcp add` и попадает в `mcp.servers`. Всё работает локально.

## Review subagent ≠ самопроверка

**Самопроверка**: агент проверяет сам себя — «предвзятость автора».

**Review subagent**: отдельный `@reviewer` из урока 4.7 с чистым контекстом,
который **не писал документ — он его проверяет**.

Он не защищает свою работу, а смотрит свежим взглядом.

---

## Что получает reviewer

- `reports/literature_comparison.md` — проверяемый артефакт;
- `SPEC.md` — требования;
- доступ к статьям/DOI;
- **только чтение**: `edit: deny`, `shell: deny`.

Не получает: историю ваших рассуждений «почему я уверен». Иначе он начнёт поддакивать.

Раздатка «Шкала доказательств».

---

## Запрос review subagent

```
@reviewer Проверь reports/literature_comparison.md.

1. Каждое утверждение — открой статью по DOI, проверь.
2. Каждый DOI — подтверди через Crossref.
3. Соответствие SPEC.md — открой SPEC.md, сравни.

Не пиши новый документ — только проверяй.
Верни таблицу: | Утверждение | Проверено? | Источник | Статус |
Если не можешь проверить — пиши «не проверено», а не «верно».
```

## Итог урока

- Zotero — своя локальная база, агент ищет по ней через MCP
- В OpenCode 2 MCP-сервер добавляется через `opencode mcp add` и `mcp.servers`
- Review subagent — отдельный `@reviewer` с read-only правами, не самопроверка
- Reviewer получает SPEC и артефакты, а не рассказ автора
- Это первый кирпичик deep-search: своя база знаний
