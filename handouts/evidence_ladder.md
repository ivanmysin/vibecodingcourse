# Шкала доказательств и протокол ревьюера

> Раздатка к урокам 2.6, 6.2 и финальной самопроверке.
> Главный вопрос: «Это доказательство или правдоподобный отчёт?»

---

## 1. Пять уровней доверия

| Уровень | Что это | Пример в науке |
|---|---|---|
| **1. Воспроизводимый факт** | результат можно повторить с нуля | удалили `results/`, перезапустили пайплайн — получилось то же |
| **2. Первичный артефакт** | файл, лог, diff, график с происхождением | `results/ranking.csv`, лог `make all`, PNG с датой и версией |
| **3. Независимое повторение** | другой агент или коллега повторил по SPEC | reviewer перезапустил проверку и получил то же |
| **4. Косвенные признаки** | «правдоподобно», «похоже на литературу» | число выглядит разумно, но источник не открыт |
| **5. Самоотчёт** | «я проверил, всё работает» | нет файла, команды и лога |

Правило: для вывода в отчёте нужен уровень **1 или 2**; для финального проекта — хотя бы один **уровень 3** (независимое повторение). Самоотчёт агента доказательством не считается.

---

## 2. Протокол независимого ревьюера

```
Ты — ревьюер, не автор. Не правь файлы.
Вход: SPEC.md, отчёт, артефакты (файлы, графики, таблицы).

Проверь:
1. Каждое число в отчёте есть в источнике? Укажи файл и строку.
2. Каждая ссылка/DOI существует? Проверь.
3. Каждый вывод следует из данных, а не из правдоподобия?
4. Есть ли в отчёте слова «кажется», «вероятно», «должно быть»?

Выход: PASS или FAIL + список замечаний с доказательствами.
Если не можешь проверить — пиши «не проверено», а не «верно».
```

---

## 3. Как использовать

- **2.6:** после визуализации и эталона — прогнать ревьюера в чистой сессии.
- **5.3:** ревьюер получает SPEC и артефакты, а не рассказ автора.
- **6.2:** ревьюер проверяет DOI и утверждения по литературе.
- **Финальный проект:** `reports/self_review.md` с доказательством по каждому критерию.

---

## 4. Чего не делать

- Не давать ревьюеру историю рассуждений автора — он начнёт поддакивать.
- Не позволять ревьюеру править файлы и затем одобрять свою правку.
- Не считать «другую LLM» доказательством уровня 1: это уровень 3, и только если она действительно перезапустила проверку.
- Не принимать «все тесты проходят» без вывода команды.
