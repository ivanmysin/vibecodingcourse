# Промпт: ЭЭГ (урок 1.2)

Один запрос — агент сам разбирается в данных и раскладывает проект
по папкам. Перед началом: рабочая папка пустая, а в ней лежит
директория `data/` с записями ЭЭГ и описанием датасета.

```
Напиши код для спектрального анализа ЭЭГ записей. Описание данных находится в файле data/Description.md

Построй три топографические карты мощности альфа-ритма (8-13 Гц) для первого испытуемого:
1. глаза закрыты — фон
2. реальное движение кистью
3. мысленное движение кистью

Напиши в reports/summary.md краткое заключение в 5-7
предложений по результатам анализа топокарт.

Создай структуру директорий для этого проекта. Разложи код и графики по разным директориям. Создай README.md файл, напиши что-нибудь разумное.

Код пиши на Python. Создай виртуальное окружение и установи необходимые пакеты.
```

---

## Что должно получиться

```
data/                   исходные записи и Description.md — не трогаем
scripts/                Python-скрипт обработки
figures/                три топокарты альфа-ритма
reports/summary.md      заключение на 5–7 предложений
README.md               описание проекта
.venv/                  окружение, созданное агентом
```

## Что лежит в `data/`

Датасет **EEG Motor Movement/Imagery** (PhysioNet, 109 испытуемых,
64 канала, 160 Гц). В `data/` уже лежат все записи — скачивать и
готовить ничего не нужно, агент найдёт их сам по `data/Description.md`.

Для урока нужен первый испытуемый (`S001`):

| Файл | Условие |
|---|---|
| `S001R02.edf` | глаза закрыты — фон, альфа-ритм выражен |
| `S001R03.edf` | реальное движение кистью |
| `S001R04.edf` | мысленное движение кистью |

## Ожидаемая картина

- альфа-ритм (8–13 Гц) сильнее всего при **закрытых глазах**,
  особенно в затылочных отведениях (O1, O2, PO8);
- при движении и его воображении альфа падает — десинхронизация;
  сильнее всего в затылочных зонах, в центральных слабее.

Проверенные числа на `S001` (средняя альфа-мощность, мкВ²/Гц):
глаза закрыты ≈ 176, движение ≈ 37, воображение ≈ 29.

## Возможные сложности

**Топокарты не строятся из-за имён каналов.** В файлах каналы
называются `Fc5.`, `Fc3.` (с точкой в конце, CamelCase). Если MNE
не сопоставляет их со стандартным монтажом, добавьте в запрос:

```
Имена каналов в EDF могут не совпадать со стандартным монтажом
MNE — приведи их к верхнему регистру без точек и подбери
стандартный монтаж (standard_1005), иначе построй карту по
координатам из файла.
```

**Скрипт падает на первом запуске.** Это нормально: скажите
«исправь ошибку и запусти снова». Агент прочитает traceback сам.

## Запасной план

Если модель долго думает или падает — попросите построить только одну
топокарту по одному условию (так быстрее). Полный прогон занимает
несколько минут; повторный запуск с нуля даёт тот же результат.
