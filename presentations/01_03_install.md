# Установка OpenCode 2

**Урок 1.3 · Модуль 1. Знакомство с OpenCode**

15 минут

---

## Единственный урок с командами руками

Сегодня ставим **одну программу** — OpenCode 2.

Это единственное место в курсе, где мы вводим команды установки вручную.
Дальше код пишет и запускает агент.

---

## Что нужно для работы

- **OpenCode 2** — сам агент
- **Python 3.10+** — среда, в которой агент запускает код

Python в курсе не трогаем руками: агент сам создаёт окружение
и ставит туда библиотеки. Но базовый Python на компьютере должен быть.

---

## Python: проверка за 10 секунд

Откройте терминал и выполните:

```
python --version
```

или, если не сработало:

```
python3 --version
```

Нужно **3.10 или выше**.

---

## Если Python не нашёлся

Два простых пути — любой подойдёт:

- **python.org/downloads** — обычный установщик, «далее-далее»
- **Anaconda** — anaconda.com/download, если хочется сразу с библиотеками - рекомендуемый путь

---

## Шаг 1. Установить OpenCode 2

**Linux / macOS / WSL** — одна команда с официального сайта:

```
curl -fsSL https://opencode.ai/v2/install | bash
```

**macOS через Homebrew:**

```
brew install anomalyco/tap/opencode-v2
```

Скрипт скачивает программу, проверяет подпись и ставит её.
Источник — только официальный `opencode.ai`, не из случайных мест.

---

## Если раньше стоял OpenCode 1

OpenCode 1 и OpenCode 2 используют одну команду `opencode`, поэтому бок о бок по умолчанию не живут.

- установщик V2 заменяет бинарь V1
- если V1 поставлен пакетным менеджером — сначала удалите его
- или обновитесь командой:

```
opencode upgrade --major
```

---

## Шаг 2. Проверить версию

```
opencode --version
```

Должно быть **2.x**.

Если печатает `1.x` — вы всё ещё в старой версии. Вернитесь к шагу 1 или выполните `opencode upgrade --major`.

---

## Шаг 3. Открыть Web-интерфейс

```
opencode pair
```

Команда печатает одноразовую ссылку (и QR-код):

```
Open a link to connect. Links work once and expire in 5 minutes.
http://127.0.0.1:49374/auth/connect/...
```

Откройте ссылку в браузере. Это и есть **OpenCode Web** — основной экран курса.

---

## Что нужно знать про `opencode pair`

- ссылка **одноразовая**, живёт **5 минут** — потом просто запустите `opencode pair` ещё раз
- вход в браузере сохраняется **30 дней**
- `opencode pair --remote` открывает сервер в интернет — в курсе **не используем**

---

## Windows: два пути

**Путь 1 (простой): приложение OpenCode Desktop**

- Скачать с `opencode.ai/download` как обычную программу
- Установить и открыть проект
- WSL и терминал не нужны

**Путь 2: WSL + CLI (сложный, но более функциональный)**

- В PowerShell от администратора: `wsl --install`, перезагрузка
- Внутри WSL — та же команда `curl -fsSL https://opencode.ai/v2/install | bash`
- Затем `opencode pair` и ссылка в браузере

---

## macOS: через Homebrew

Если установлен Homebrew:

```
brew install anomalyco/tap/opencode-v2
```

Работает так же, как способ с `curl`. Для V1 старая формула была `anomalyco/tap/opencode` — для V2 нужен суффикс `-v2`.

---

## Чек-лист установки

Все три пункта должны быть «зелёными»:

- [ ] `python3 --version` печатает `Python 3.10+`
- [ ] `opencode --version` печатает `2.x`
- [ ] `opencode pair` открывает Web-интерфейс в браузере

---

## Если что-то не открылось

- **Ссылка истекла** — запустите `opencode pair` ещё раз.
- **Нужен адрес сервера** — `opencode service status` печатает текущий URL.
- **Нужен фиксированный порт** — `opencode service set port 4096`, затем `opencode service restart` и снова `opencode pair`.
- **Порт занят** — не задавайте порт вручную, используйте тот, что предложит OpenCode.
- **Открылся старый интерфейс** — проверьте `opencode --version`; скорее всего, остался V1.
